Examples

Practical implementations across different ecosystems.

1. Decoupling TallyPrime Runtimes

In the KeshavSoft Tally ecosystem, tally-spec owns the data contracts, @keshavsoft/api-tree builds the navigable tree, and tally-xml-tdl executes raw XML over HTTP:

import apiTree from "@keshavsoft/api-tree";
import { source, apiPaths } from "tally-spec";
import tallyXmlExecutor from "./engine/execution/index.js";

// Builds callable tree: app.masters.unit.all(), app.company.fetch()
const app = apiTree(source, apiPaths, tallyXmlExecutor);

// Fetch live units directly from TallyPrime
const units = await app.masters.unit.all();
console.log(units);

2. Dynamic REST / HTTP Client

Instead of manually writing HTTP client SDKs for every microservice, generate one on the fly from an endpoint schema:

import apiTree from "@keshavsoft/api-tree";

const endpoints = {
    api: {
        v1: {
            users: {
                get: { method: "GET", url: "https://api.example.com/users" }
            }
        }
    }
};

const apiPaths = ["api.v1.users.get"];

const httpExecutor = async ({ inLeafSpec, inParam }) => {
    const response = await fetch(`${inLeafSpec.url}/${inParam}`, {
        method: inLeafSpec.method
    });
    return response.json();
};

const client = apiTree(endpoints, apiPaths, httpExecutor);

// Invokes GET https://api.example.com/users/42
const user = await client.v1.users.get(42);

3. CLI Command Dispatcher

Map command lines directly to business logic handlers using path notation:

import apiTree from "@keshavsoft/api-tree";

const commands = {
    cli: {
        auth: {
            login: { description: "Authenticate user session" },
            logout: { description: "Terminate session" }
        }
    }
};

const cli = apiTree(commands, ["cli.auth.login", "cli.auth.logout"], async ({ inRoutePath, inParam }) => {
    console.log(`Executing ${inRoutePath} with credentials:`, inParam);
});

await cli.auth.login({ username: "admin" });
