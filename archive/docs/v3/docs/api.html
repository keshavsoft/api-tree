API Reference

Complete contract specifications and execution context reference.

Function Signatures

@keshavsoft/api-tree supports both positional arguments and the named object convention:

Positional Call

import apiTree from "@keshavsoft/api-tree";

const api = apiTree(source, apiPaths, executor, options);

Named Object Call

import apiTree from "@keshavsoft/api-tree";

const api = apiTree({
    inSource: source,
    inApiPaths: apiPaths,
    inExecutor: executor,
    inOptions: { inUnwrapRoot: false }
});

Execution Context Reference

Whenever an attached leaf method is called (e.g. app.users.profile.fetch("123", "extra")), your executor receives a single standardized context object:

Property Type Description
inRoutePath string The full dot-notation route path (e.g. "app.users.profile.fetch").
inParam any The primary argument passed to the leaf method.
inArgs any[] Array containing all subsequent arguments passed after inParam.
inLeafSpec object | undefined The resolved leaf definition object found in source.json.
inSource object The complete raw source schema object.
inPathSegments string[] Array of individual path segments (e.g. ["app", "users", "profile", "fetch"]).

Options (inOptions)

Option Type Default Description
inUnwrapRoot boolean true When true and all paths share a common root segment, unwraps the root. Set to false to preserve the full root namespace.
