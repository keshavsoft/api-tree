Guarantees & Validation

Fail-fast contract validation and reliability guarantees.

Fail-Fast Philosophy

@keshavsoft/api-tree strictly enforces contract integrity before building any runtime objects. If any input is malformed, it throws a descriptive TypeError immediately so errors never leak into runtime invocations.

Validation Rules

1. Source Object

  • Must be a non-null plain JavaScript object.
  • Arrays, primitives, and null throw: TypeError: source must be a JSON object.

2. API Paths Array

  • Must be a JavaScript Array. Non-arrays throw: TypeError: apiPaths must be an array of strings.
  • Every element must be a string. Non-string elements throw: TypeError: apiPaths must be an array of strings. apiPaths[i] must be a string.
  • Empty strings throw: TypeError: apiPaths[i] must not be an empty string.
  • Paths with empty segments (such as "users..fetch" or "users.") throw: TypeError: apiPaths[i] contains an invalid empty path segment.

3. Executor Function

  • Must be a callable function. Non-functions throw: TypeError: executor must be a function.

4. Options

  • If provided, options must be a plain object. Passing non-objects throws: TypeError: options must be an object if provided.
