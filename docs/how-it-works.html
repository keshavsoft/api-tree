How It Works

Under the hood of the dynamic runtime routing engine.

1. The Assembly Pipeline

When you call apiTree(source, apiPaths, executor), the engine performs three synchronous steps:

  1. Pre-Flight Validation: Ensures that source is a valid plain object, apiPaths contains valid non-empty string segments, and executor is a callable function.
  2. Tree Branching: Splits each dotted path into segments (e.g. ["app", "users", "profile", "fetch"]) and recursively builds nested JavaScript objects.
  3. Leaf Handler Attachment: The final segment becomes an async callable leaf function wired to your executor.

2. Pre-Resolved Leaf Specifications (inLeafSpec)

In older patterns, executors had to manually traverse inSource to locate their definition. In v2, api-tree automatically resolves the leaf object from source.json during tree construction:

const executor = async ({ inRoutePath, inLeafSpec, inParam }) => {
    // inLeafSpec is already extracted from source:
    // { action: "fetch", resource: "User", timeout: 5000 }
    console.log(inLeafSpec.resource);
};

3. Intelligent Root Handling

Depending on your architecture, your API paths may belong to a single domain or multiple domains:

  • Single-Root Auto-Unwrapping: When all paths start with the same root (e.g. ["app.users.fetch", "app.reports.fetch"]), api-tree automatically unwraps app, giving you clean access like api.users.fetch().
  • Multi-Root Domain Preservation: When paths belong to multiple roots (e.g. ["users.list", "orders.create"]), api-tree preserves both roots (api.users.list() and api.orders.create()).
  • Explicit Configuration: You can pass { inUnwrapRoot: false } to force keeping the root prefix intact.

4. Hybrid Callable Branches

In JavaScript, functions are objects. If your schema defines both a parent route and a child route (such as api.users and api.users.profile), api-tree seamlessly attaches the child branch onto the parent function:

await api.users();         // Calls the parent handler
await api.users.profile(); // Calls the child handler
