api-tree

A small runtime API-tree builder.

The story

A domain repository already knows its structure and its execution logic. api-tree does not replace that logic. It only turns a flat list of API paths into a callable runtime tree.

source JSON + API paths + executor
                 ↓
              api-tree
                 ↓
       app.users.profile.fetch()

Three inputs

  • source — source/domain JSON
  • apiPaths — flat array of dotted paths
  • executor — external function that performs the operation

Why separate it?

The route mechanism is reusable. Tally XML, Tally JSON, Tally Simple, or another domain can keep its own JSON and execution code while sharing the same runtime API-tree mechanism.

Validation

The public function rejects invalid source, API-path arrays, and executors with clear TypeErrors.
