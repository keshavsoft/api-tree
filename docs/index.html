api-tree

A small, zero-dependency runtime API-tree builder.

We had a situation in our codebase: we were writing function after function just to expose different endpoints.

Yet under the hood, every single one of those functions was doing the exact same thing: calling one core execution function. The only difference from endpoint to endpoint was a few variables—like a resource name, an action, or a query string.

Writing dozens of nearly identical wrapper functions created boilerplate, duplicated code, and made maintenance tedious.

What We Did

We separated the parts that never change from the parts that do:

  • The Single Function (Executor): The core execution engine is written exactly once. It handles the network requests, headers, and response parsing.
  • The Variables (source.json): The parameters that vary per endpoint are moved into a clean JSON contract.
  • The Routes (api.json): The allowed endpoints are defined in a flat array of dot-notation paths.

api-tree marries the single executor function with the variable JSON, dynamically building the callable dot-notation tree at runtime.

The Code

Instead of writing endless wrapper functions like this:

// The repetitive pattern
export const getUnits = () => execute({ resource: "Unit" });
export const getLedgers = () => execute({ resource: "Ledger" });
export const getCompany = () => execute({ resource: "Company" });

You write your executor once, put your variables in JSON, and let api-tree generate the surface:

import apiTree from "@keshavsoft/api-tree";

// 1. Only the variables
const source = {
    app: {
        masters: {
            unit: { all: { resource: "Unit", action: "fetch" } }
        }
    }
};

const apiPaths = ["app.masters.unit.all"];

// 2. The single executor function
const execute = async ({ inLeafSpec, inParam }) => {
    return await dispatch(inLeafSpec.resource, inParam);
};

// 3. Build the callable tree
const app = apiTree(source, apiPaths, execute);

// 4. Call naturally
const units = await app.masters.unit.all();

When you need a new endpoint tomorrow, you do not write a new JavaScript function. You simply add a new entry to your JSON file, and it is immediately available on the tree.
