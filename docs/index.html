@keshavsoft/api-tree

A declarative, ultra-lean routing engine that turns source schemas, API paths, and an external executor into a callable runtime API tree.

Runtime Tree = Source Schema (JSON) + API Paths (Routes) + Custom Executor

Core Architecture

@keshavsoft/api-tree decouples specification contracts from runtime execution:

1. Source Schema

The single source of truth containing leaf specifications, metadata, and domain contracts.

2. API Paths

A flat, declarative array of dotted routes (e.g. app.users.profile.fetch).

3. Custom Executor

A pure execution handler that receives standardized context and executes the operation.

Quick Start

import apiTree from "@keshavsoft/api-tree";

const source = {
  app: {
    users: {
      profile: {
        fetch: { action: "fetch", resource: "User" }
      }
    }
  }
};

const apiPaths = ["app.users.profile.fetch"];

const executor = async ({ inRoutePath, inLeafSpec, inParam }) => {
  return { id: inParam, action: inLeafSpec.action };
};

const api = apiTree(source, apiPaths, executor);

// Call the navigable tree!
const result = await api.users.profile.fetch("123");
console.log(result); // { id: "123", action: "fetch" }

Execution Context

When an attached leaf function is invoked, your executor receives a rich context object:

Property Type Description
inRoutePath string The full dot-notation route path.
inParam any First argument passed to the leaf.
inArgs any[] Array of all additional arguments.
inLeafSpec object Pre-resolved leaf definition from source.json.
inSource object The raw source schema object.
